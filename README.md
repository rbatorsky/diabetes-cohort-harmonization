# Harmonization Pipeline for BPRHS and PROSPECT Datasets

This repository contains the Python pipeline used to harmonize the Boston Puerto Rican Health Study (BPRHS) and PROSPECT datasets across three domains: Social Determinants of Health (SDOH), Health, and Food Frequency Questionnaire (FFQ).

The repository contains two versions of the pipeline, with the same code:

- pipeline_synthetic_data/ : ready to run with the synthetic datasets included in the repository. Start here to test the pipeline.
- pipeline/ : for the original BPRHS and PROSPECT data, which must be requested from UMass Lowell and Harvard University (see the README in that folder).

ml_scripts/ contains the R scripts for the Random Forest worked example reported in the manuscript.

Installation and execution instructions are in the README of each pipeline folder.
